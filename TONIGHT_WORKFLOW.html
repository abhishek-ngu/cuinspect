Phase 2: Create Test CUDA Binary (10 min)

10 min Generate .cubin with Debug Info
1

Go to Project Root (not build/)

cd /mnt/c/Nvidia/cuinspect
2

Create Test Kernel File

cat > test.cu << 'EOF'
__global__ void add_kernel(float* a, float* b, float* c, int n) {
    int i = blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) c[i] = a[i] + b[i];
}
__global__ void mul_kernel(float* a, float* b, float* c, int n) {
    int i = blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) c[i] = a[i] * b[i];
}
EOF
3

Compile to CUBIN (critical: -cubin not -ptx, and -g for debug info)

nvcc -cubin -arch=sm_90 -g -o test.cubin test.cu
4

Verify CUBIN Created

ls -la test.cubin
# Should be ~20-50 KB
Critical Flags: -cubin (not -ptx) + -g (debug info) + -arch=sm_90 (Hopper). Without -g, no DWARF sections exist.

Troubleshooting Quick Reference

🔴 "LLVMConfig.cmake not found"

find /usr -name "LLVMConfig.cmake" → use that path in cmake -DLLVM_DIR=

🔴 "nvcc: command not found"

sudo apt install nvidia-cuda-toolkit or download from NVIDIA website

🔴 "No DWARF sections found"

Must compile with -g flag: nvcc -cubin -g -arch=sm_90

🔴 "Permission denied on binary"

chmod +x build/cuinspect

🔴 "EM_NVPTX unknown"

Need LLVM 18+. Check: llvm-config --version

🔴 "GitHub Pages not loading"

Wait 5 min after enabling. Check Actions tab for deploy status. Ensure index.html is in root.
